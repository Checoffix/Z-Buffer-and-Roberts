# Z-Buffer & Roberts Algorithm (2023)

Учебная лабораторная работа по дисциплине «Компьютерная графика» (НГТУ АВТФ, 2 курс).

Реализовано:
- Программная сканлайн-растеризация 3D-полигонов (Z-buffering) без использования графических API (DirectX / OpenGL).
- Алгоритм Робертса для отсечения невидимых граней и поверхностей.
- Парсинг 3D-моделей (.obj) и расчет освещения по нормалям.
